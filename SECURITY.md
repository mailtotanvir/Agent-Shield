# Security Policy

AgentShield is pre-release software and has no supported production version yet.

Report suspected vulnerabilities privately through GitHub Security Advisories
for `mailtotanvir/Agent-Shield`. Do not include live tokens, credentials, private
keys, customer data, cloud identifiers, or exploit traffic against systems you
do not own. Use synthetic canaries and the local test harness for reproductions.

Security reports should include affected commit/version, impact, prerequisites,
minimal reproduction, and suggested mitigation when known. Public disclosure
should wait until a fix and coordinated release are available.
